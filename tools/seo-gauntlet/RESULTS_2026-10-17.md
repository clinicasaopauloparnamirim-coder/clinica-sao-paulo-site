## 4. Performance, Search Console e GA4 — limites reais do teste

- **PageSpeed Insights API:** a chamada pública retornou HTTP 429 / quota zero para o projeto consumidor dessa API. O adaptador próprio trata isso como quota_limited e não inventa scores. O workflow do próprio GitHub Actions também registrou skipped_no_api_key porque PSI_API_KEY não está configurado como secret.
- **PageSpeed web:** a página consultada informou ausência de dados de campo CrUX suficientes para a URL; as métricas Lighthouse não ficaram disponíveis na extração pública usada. A ferramenta Lighthouse conectada também foi negada pelo plano Free.
- **Google Search Console:** a conexão consultada não disponibilizou sites/propriedades.
- **GA4:** a conexão consultada não disponibilizou contas/propriedades.

Por isso, não reportamos métricas fictícias de Core Web Vitals, estado de indexação no Google, cliques/impressões orgânicas ou conversões. Esses testes seguem pendentes de quota/credenciais de leitura válidas.
