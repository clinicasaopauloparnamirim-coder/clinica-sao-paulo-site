# seo-gsc-audit

## Procedure
1. Confirm the connected GSC property.
2. Audit the campaign landing URLs for status, canonical, indexability, title, description, H1, schema and content depth.
3. Compare search visibility with intended paid-search coverage.
4. Separate paid-landing readiness from organic-indexing issues.
5. Report exact URLs and concrete corrections.
Do not publish SEO changes automatically.
