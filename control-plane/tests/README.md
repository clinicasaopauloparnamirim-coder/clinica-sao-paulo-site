# Control Tower Tests

Tests follow the Gauntlet Loop:

1. Define the claim.
2. Define observable success criteria.
3. Execute the smallest safe test.
4. Capture evidence.
5. Re-read the real state.
6. Critique failures and false positives.
7. Re-run after correction.
8. Record the final verdict.

Verdicts:

- PASS — directly verified.
- FAIL — directly disproven.
- INCONCLUSIVE — insufficient evidence.
- BLOCKED — required capability/permission is unavailable.
