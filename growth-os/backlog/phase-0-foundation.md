# Fase 0 — Foundation

## Objetivo
Transformar a foundation em sistema operacional independente do Control Tower.

### Bloco 1 — Verdade do negócio
- confirmar entity
- confirmar serviços
- confirmar localização
- confirmar oferta
- confirmar links e canais
- confirmar políticas de comunicação

### Bloco 2 — Dados
- conectar fontes autorizadas
- normalizar GSC/analytics
- mapear consultas
- mapear páginas
- mapear conversões
- construir baseline

### Bloco 3 — SEO/semântica
- construir mapa de entidades
- construir mapa de intenção
- identificar clusters
- mapear páginas canônicas
- definir interlinking

### Bloco 4 — Local/GEO
- auditar presença local
- validar consistência de entidade
- mapear diretórios legítimos
- orientar FAQ por perguntas reais
- melhorar respostas e prova

### Bloco 5 — Conteúdo
- calendário por cluster
- template de carrossel
- template de Stories
- template de Reel
- template de FAQ
- template de GBP post

### Bloco 6 — Conversão
- fluxo WhatsApp
- handoff
- scripts
- SLA
- retorno de resultado

### Bloco 7 — QA
- schema
- links
- indexação
- performance
- acessibilidade
- analytics/UTM
- regressão

### Critério de passagem
A Fase 0 só termina quando a estrutura estiver auditada, a fonte de verdade estiver definida e os próximos módulos tiverem backlog verificável.
