# Clínica São Paulo — Growth OS

Sistema-mãe de marketing, aquisição, autoridade local, conteúdo, SEO, GEO, vendas digitais, captação, reputação e passagem do online para a recepção.

## Separação operacional
- **Control Tower:** operações técnicas e integrações existentes. Não é substituído.
- **Growth OS:** estratégia, inteligência, conhecimento, conteúdo, SEO/SEO semântico, GEO/AI Search, presença local, persuasão, vendas digitais, reputação, experimentação e handoff para a recepção.
- O Growth OS pode consumir dados autorizados do Control Tower, mas não depende de sua estrutura interna para existir.

## Princípio
Descoberta → compreensão → confiança → ação → captação → atendimento → agendamento → experiência → reputação → aprendizado.

## Regra de execução
**Entender → definir o que é “feito” → investigar → planejar → executar → verificar → criticar → reverificar → reportar evidências.**
