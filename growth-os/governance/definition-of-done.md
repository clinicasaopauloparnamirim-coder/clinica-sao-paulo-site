# Definition of Done

Um item só pode ser marcado como concluído quando:
1. o requisito foi entendido;
2. a solução foi definida;
3. a implementação foi concluída;
4. o artefato real foi lido de volta;
5. testes/validações aplicáveis passaram;
6. o resultado esperado foi comparado com o observado;
7. riscos e limitações foram registrados;
8. evidência foi anexada.

Estados:
- TODO
- IN PROGRESS
- BLOCKED
- READY FOR VERIFY
- VERIFIED
- INCONCLUSIVE

Nunca converter IN PROGRESS diretamente em VERIFIED.
